This folder contains static assets deployed to the public S3 bucket via the StaticContent stack.

Structure:
- styles/ : project-level CSS overrides (e.g., style.css)
- assets/ : HTML5UP template CSS/JS/webfonts (deployed from html5up-verti/assets)
- images/ : HTML5UP template images (deployed from html5up-verti/images)

Do not place secrets here. All files are publicly readable.
